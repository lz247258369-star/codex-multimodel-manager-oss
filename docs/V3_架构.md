# Codex Multi-Model Manager V3 架构

```text
Provider APIs
   │
   ├── OpenAI /models
   ├── MiMo /models（若当前账户/端点提供）
   ├── Alibaba Model Studio /models（若当前端点提供）
   ├── xAI /v1/models
   ├── Groq /openai/v1/models
   └── OpenRouter /api/v1/models
             │
             ▼
      Discovery Engine
             │
             ├── 首次：建立 baseline
             └── 后续：diff 新 model ID
             │
             ▼
       Candidate Registry
             │
             ├── NEW
             ├── RESPONSES_PASS
             ├── VERIFIED
             └── PROBE_FAILED
             │
        用户明确批准
             ▼
       Approved Registry
             │
             ▼
  ~/.codex/config.toml
  CODEX AUTO MODELS block
             │
             ▼
      Codex Model Switcher
```

## 安全边界

自动：
- GET `/models`
- diff
- 写扫描报告

必须确认：
- POST `/responses`（可能计费）
- Tool Calling Probe（可能计费）
- 把模型写入 Codex profile

永不自动：
- 改项目代码
- reset/stash/clean
- commit/push
- 切换默认主力
- 删除旧模型
