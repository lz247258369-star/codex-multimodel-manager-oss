# Codex Skill

This directory contains the installable Codex Skill payload.

Installable folder:

```text
skill/codex-multimodel-manager/
├─ SKILL.md
├─ scripts/
└─ references/
```

The Windows installer copies that folder to:

```text
$CODEX_HOME/skills/codex-multimodel-manager/
```

Do not put API keys, auth files, project data, or runtime state in this directory.
